# 🔍 Ridge vs Lasso Regression (Day 4)

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![scikit--learn](https://img.shields.io/badge/scikit----learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white)

Compares **Ridge** and **Lasso** regression on a sample house-price dataset.

| Model | MSE | R² |
|---|---|---|
| Ridge | 119,645,833.33 | 0.8732 |
| Lasso | 122,101,258.55 | 0.8701 |

- **Ridge** shrinks coefficients but keeps all features
- **Lasso** can drive coefficients to zero (built-in feature selection)

```bash
pip install scikit-learn numpy matplotlib
python Ridgeandlasso.py
```
